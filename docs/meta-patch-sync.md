# TFT-META-PATCH-SYNC-1
## Deploy
Apply 012 first if missing, then apply `013_tft_meta_patch_sync.sql` in Supabase SQL Editor. Run **Sync TFT patch calendar** before collecting. It runs hourly at minute 7 and shares the collector concurrency group. Collector runs at minute 17. Sync requires only existing Supabase secrets and does not call Riot match API or delete data.
## Policy
- Source 1: official TFT patch notes; source 2: official KR-language patch schedule (dates in Pacific time). The schedule is NOT a KR deployment completion notice. Never use publication alone as rollout.
- For unparseable Match API versions, use the later of publication and scheduled Pacific midnight + 48 hours as a conservative **estimate**. Store the candidate, expected set (official patch naming convention), first observation, source and interval, and a conservative cutoff at next scheduled Pacific midnight or the newer published article. No raw patch rewrite. If calendar is unavailable or stale, no new inferred patch confirmation without owner evidence.
- A matching single-set calendar cohort is displayed as reference data below 30 matches. At 30 complete eligible matches with no conflicting board versions/sets, promote to schedule-estimated patch scope, explicitly labelled in UI. Direct parseable match evidence remains primary. Generic preview remains clearly patch-unconfirmed.
- If verified independent KR rollout evidence exists, SQL Editor owner can call `public.set_tft_verified_kr_boundary(patch, rollout_at, evidence_url)`. Timestamp represents a verified time by which KR was live; the function records the operator attestation, not an independent verification. No fake date or automatic exact rollout verification. For a new patch the prior interval is conservatively closed; raw recent unknown boards remain recoverable.
- Raw retention remains seven days when cleanup is enabled; expired boards may now be cleaned even while awaiting a patch, but recent NULL versions are retained.
- The current 18.7 official note was published 2026-11-17 19:00 UTC; official schedule lists Nov 17 Pacific. If both fetches succeed, the estimated eligibility begins 2026-11-19 19:00 UTC (Nov 20 04:00 KST), not the actual deployment timestamp. Existing Nov 27 boards can qualify immediately if still within seven days.
- If schedule parsing fails because the website changes HTML, sync logs the fallback; check the official source and update parser. No automatic exact KR rollout API was verified.
