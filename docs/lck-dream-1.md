# LCK-DREAM-1
Route /esports/lck/dream-team. Uses the existing curated LCK 2027 snapshot, not live data. Candidate IDs are role + lowercase player, with confirmed contract rows taking precedence over market and report-only rows. No additional server calls, dependencies or DB. Share links encode version, team name, theme and five stable IDs using URLSearchParams; unknown or role-mismatched IDs clear on import. Local browser storage is optional. The fan card uses Canvas text and shapes only, 1200x900 PNG, no third-party photos or logos. No ability ratings, predictions, or implied official team. Smoke checks should include mobile picking, reload/localStorage, opening a share link in a new tab, download PNG and canonical metadata. Run npm test and npm run build before deployment.
