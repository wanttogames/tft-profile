# 수집형 TFT 프로필 카드

- 검색 결과 최상단에 메인 카드를 표시합니다. 기존 성장/연속 기록/업적은 바로 아래 펼침 영역에서 확인합니다.
- 공식 게임 카드나 티어 아이콘을 사용하지 않는 독자적인 프레임, 기하학 엠블럼, 색상 체계입니다.
- Iron~Challenger의 10개 티어와 Unranked 프레임을 지원합니다. 티어는 시각적 표현만 바꾸며 점수 계산은 기존 그대로입니다.
- 최근 30경기의 8개 점수, 평균 등수/TOP4/1등률, 칭호, 선호 챔피언/활성 특성 TOP3, 한줄 분석을 표시합니다.
- 760px 이하에서는 세로형 카드로 전환합니다. 능력치는 2열, 긴 Riot ID와 이름은 줄바꿈합니다.
- `내 카드 이미지로 공유` → `PNG 이미지 저장`으로 900×1260 카드를 저장합니다. 미리보기 canvas를 그대로 내보냅니다.
- 공유 카드는 외부 이미지를 불러오지 않습니다. 한글명과 자체 그래픽만 사용하므로 이미지 CORS 문제를 피합니다. 이름/통계는 메인 카드와 같은 표시 모델을 사용합니다.
- 다운로드한 PNG를 카카오톡이나 SNS에서 직접 첨부합니다. 사이트가 메시지를 자동 발송하거나 영구 수집 기록을 만들지는 않습니다.
- 새 환경변수, SQL, npm 의존성은 없습니다. API/Collector/메타/분석 계산은 변경하지 않았습니다.
