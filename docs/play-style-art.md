# 플레이스타일과 프로필 아트

## 표본과 보존 범위

운영 API는 기존 호출량 절감 설계에 따라 최근 30경기를 유지합니다. 카드도 실제 분석 수를 표시합니다. 이번 요청의 50경기 분류는 `playerStyle()` 및 `playerScoreContext(games, assets, 50)`에서 최대 50개의 제공된 경기로 처리할 수 있습니다. 30경기를 50경기라고 표시하거나 API 상세 조회를 추가하지 않습니다. 기존 8개 점수 공식, Collector, 메타, 캐시는 유지됩니다.

## 대표 스타일 12종

안정적 순방형 / 고점 폭발형 / 유연한 운영가 / 한 우물 장인 / 후반 운영형 / 완성도 중시형 / 저점 방어형 / 변동성 높은 도전자 / 1등 지향형 / 시너지 전문형 / 핵심 캐리 집중형 / 덱 탐험가.

여기에 중립 `균형 운영형`, `분석 표본 부족` 상태가 있습니다. 20경기 미만 또는 최종 보드/활성 특성 기록이 80% 미만이면 억지로 분류하지 않습니다. 룰은 최소 3개 신호를 확인하며 앞에서 일치하는 하나를 선택합니다. 같은 자료에서 중복 조건을 만족하면 복합 집중도 → 뚜렷한 성적/최종 보드 → 전문형 → 넓은 성향 순서를 사용합니다. 각 룰의 코드와 설명이 계산 기준입니다. 보조 태그는 근거가 있는 성향을 3개까지 선택하며, 뚜렷한 성향이 부족하면 측정값 태그로 최소 2개를 채웁니다. 표본 부족은 태그를 만들지 않습니다.

활성 특성은 tier_current > 0만 반영합니다. 캐리 집중 태그는 80% 이상 경기에서 아이템 2개 이상 장착 유닛이 확인되어야 합니다. 최종 장착 보드 기준 추정이며 실제 캐리 역할·운영 의도·경기 중 전환·리스크 감수 의도를 확정하지 않습니다.

## 아트 구조

- `analytics/playStyleClassifier.ts`: 대표 스타일과 우선순위
- `analytics/playStyleTags.ts`: 보조 성향과 중립 측정값 태그
- `analytics/playStyleIllustration.ts`: 모든 스타일의 illustrationTheme / visualKeywords / backgroundMood / accentStyle / emblemStyle / shortFlavorText 및 벡터 색상·문양
- `profile-card/styleArt.ts`: 독자적인 600×240 벡터 장면
- `components/PlayStyleArt.vue`: 메인 카드의 SVG 아트
- `profile-card/renderShareCard.ts`: 같은 벡터 장면을 PNG에 렌더링

티어 색상은 바깥 프레임에 유지되고 대표 스타일은 내부 배경·광선/궤도/성채 문양·상징물·능력치 색상을 바꿉니다. 일러스트 테마는 판타지 장식이며 실제 경기에서 관측한 캐릭터가 아닙니다. 공식 게임 아트나 카드 디자인을 복제하지 않았습니다. 현재 아트는 자체 벡터 문장/배경이며 생성형 캐릭터 원화는 아닙니다. 나중에 원화를 추가할 때 visualKeywords와 illustrationTheme을 제작 기준으로 사용할 수 있습니다.

공유 카드는 900×1500 PNG입니다. 미리보기 그대로 저장하며 외부 이미지를 쓰지 않아 CORS 의존성이 없습니다. 대표 스타일·태그·아트 테마·8개 점수·선호 목록·한줄 분석을 포함합니다.
