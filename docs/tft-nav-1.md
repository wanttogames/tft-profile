# TFT-NAV-1
Five top-level groups (TFT analysis, calculators, season, LCK, esports history) and 19 real content links; service links in footer and mobile help area. src/config/navigation.ts is the shared menu registry for header/footer/home discovery and LCK section tabs. Existing routes, SEO pages, sitemap, data, API and dependencies are unchanged. Desktop disclosure buttons open on click, close via outside pointer/focus or Escape; keyboard Tab/Shift+Tab follows native links and buttons; no ARIA menu role or mouse-only interactions. Mobile <=900px uses a scrollable hamburger disclosure with one expanded category, defaults to active group. Escape collapses active group, then mobile menu; breakpoint change resets state. Server-rendered HTML retains anchor destinations; grouped footer is always visible. LCK local navigation shows the relevant six or three links and one cross-category entry. Home navigation links are grouped; full home portal redesign is deferred to TFT-HOME-1. Verify desktop and mobile keyboard/touch behavior in browser and run npm test / npm run build.
